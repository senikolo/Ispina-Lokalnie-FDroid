# Repozytorium na GitHub Pages

GitHub Pages udostępnia stronę informacyjną oraz pliki F-Droid w katalogu `repo/`.

Workflow **Publikuj repozytorium F-Droid** automatycznie pobiera najnowszy stabilny APK, sprawdza jego sumę i podpis, generuje podpisany indeks oraz publikuje APK i indeks pod adresem repozytorium.

Nie kopiuj tu ręcznie plików ani nie dodawaj `config.yml`, klucza podpisującego lub haseł. Do dodawania repozytorium w aplikacji F-Droid użyj adresu `https://senikolo.github.io/Ispina-Lokalnie-FDroid/repo`.
