Repozytorium aplikacji

Ispina Lokalnie

To repozytorium udostępnia aplikację Ispina Lokalnie przez klienta F-Droid. Prowadzi je autor aplikacji; nie jest częścią głównego katalogu F-Droid.

Status

Repozytorium będzie gotowe do dodania po opublikowaniu podpisanego indeksu i plików aplikacji.

Adres repozytorium

Po uruchomieniu repozytorium dodaj ten adres w aplikacji F-Droid:

https://senikolo.github.io/Ispina-Lokalnie-FDroid/repo

Jak dodać źródło w F-Droid

  1. Otwórz Ustawienia → Repozytoria.
  2. Wybierz Dodaj repozytorium.
  3. Wklej powyższy adres i zatwierdź.

Informacje o aplikacji

  • Nazwa: Ispina Lokalnie Live
  • Identyfikator: com.ispina.mldcheck
  • Wymagany Android: 6.0 lub nowszy
  • APK pochodzi z wydań autora; repozytorium nie kompiluje aplikacji ze źródeł.

Aktualne wydania znajdziesz w repozytorium aplikacji na GitHubie.

Repozytorium prowadzi senikolo.
